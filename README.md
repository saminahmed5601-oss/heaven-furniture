# Heaven Furniture Mart — Digital Atelier

> **Bespoke Furniture & Interior Styling** · Agrabad, Chattogram, Bangladesh  
> *Designed. Crafted. Customized. — পরিকল্পিত · হস্তনির্মিত · আপনার পছন্দমতো*

An architectural web application and digital showroom crafted for **Heaven Furniture Mart**, a premier bespoke furniture atelier established on Agrabad Access Road in Chattogram.

---

## ✨ Features & Architecture

- **Bespoke Commission Workflow:** Interactive quote modal with environment selection (Living Atelier, Master Sanctuary, Grand Dining, Executive Suite), wood selection (Seasoned Segun Teak, Chittagong Hardwood), and automatic WhatsApp concierge routing.
- **Curated Spaces Catalog:** Architectural furniture suites tailored to exact room footprints with dynamic inquiry pre-filling.
- **Craftsmanship & Workshop Showcase:** In-house CNC precision joinery video stream paired with 4-phase production methodology.
- **Wood-Grain Pedigree Timeline:** Responsive generational timeline tracking atelier milestones with interactive accordion details.
- **Social Proof & Trust:** Live marquee carousel with verified 4.8-star Google ratings and physical showroom Google Maps card.
- **Ultra-Smooth Momentum Scrolling:** Integrated [Lenis](https://lenis.darkroom.engineering/) smooth scroll engine with mobile inertia optimizations and zero CLS.
- **Bilingual Typographic Nuance:** Cormorant Garamond serif display, Plus Jakarta Sans body, and Noto Serif Bengali.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) with custom `@theme` tokens
- **Smooth Scrolling:** [Lenis](https://github.com/darkroomengineering/lenis)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** TypeScript 5

## 🚀 Getting Started

### Prerequisites
- Node.js 18.18+ or later
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/saminahmed5601-oss/heaven-furniture.git

# Navigate into directory
cd heaven-furniture

# Install dependencies
npm install
```

### Running Locally

```bash
# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Start production server
npm start
```
